# School: Learn to Contribute

Welcome to the School. This is where you learn to understand and contribute to the american-revolution project.

**Start here:** Read the lessons in order. Each one teaches you one part of the process.

## The Lessons

1. **[What Is This Project?](lesson-1-what-is-this.md)** — Understand the timeline structure
2. **[The Rules](lesson-2-the-rules.md)** — Learn the one strict requirement (release notes)
3. **[The Format](lesson-3-the-format.md)** — See exactly how to write an event
4. **[Adding an Event](lesson-4-adding-an-event.md)** — Step-by-step walkthrough
5. **[Running Tests](lesson-5-running-tests.md)** — Test your work before you commit
6. **[Commit and Pull Request](lesson-6-commit-and-pr.md)** — Ship your contribution
7. **[Common Mistakes](lesson-7-common-mistakes.md)** — Avoid the traps
8. **[You're Ready](lesson-8-youre-ready.md)** — What to do next

## Quick Reference

- **timeline.json** — The structured data file with all events
- **RELEASE_NOTES.md** — Where you add your one-line description
- **tests/timeline.test.mjs** — The test suite that validates your work
- **.github/workflows/ci.yml** — The CI pipeline that runs on every PR

---

**Estimated time:** 20 minutes to read all lessons. 10 minutes to add your first event.
