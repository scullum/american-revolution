# Lesson 1: What Is This Project?

**What we're building:** A timeline of major events in American history, from 1765 to the present. The timeline lives in one file: `timeline.json`.

**Why it matters:** This project teaches you how to work with structured data, write clean contributions, and follow a team's standards.

**Your first task:** Open `timeline.json` in your editor. You'll see a list of events. Each event has:
- `year` — the year it happened (a number)
- `title` — the event's name (text)
- `summary` — what happened (text)

That's the whole structure. Six events are there now. Your job will be to add more.

**Example event:**
```json
{
  "year": 1776,
  "title": "Declaration of Independence",
  "summary": "The Continental Congress formally declared the thirteen colonies independent from British rule on July 4th."
}
```
